## 🎯 Event Overview

**RootAccess 2K24** is a prestigious pan-India Capture The Flag (CTF) competition that brought together cybersecurity enthusiasts, professionals, and students from across the country.

### Event Highlights

- 🌍 **Pan-India Event** - Participants from multiple states
- 👥 **300-400 Teams** - Diverse skill levels from beginners to experts
- 🏆 **Competitive Platform** - Real-world security challenges
- 💡 **Learning Focus** - Educational cybersecurity problems
- 🔒 **Variety of Domains** - Multiple challenge categories
